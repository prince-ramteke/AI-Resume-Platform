# M6.1 — Design + App Shell Implementation Plan

> **For agentic workers:** implement this plan task-by-task, in order. Steps use checkbox
> (`- [ ]`) syntax for tracking. This is a **planning document** — no source files are
> created until the plan is approved. Per repo boundary, **commit only after the whole M6.1
> slice is reviewed and approved.**

**Goal:** Establish the frontend foundation — approved design tokens, providers, Axios
interceptors, in-memory auth context, route guards, core UI primitives, and the app shell —
so M6.2+ can build feature screens against a stable base.

**Architecture:** Provider stack `QueryClientProvider → AuthProvider → BrowserRouter`. Token
lives in `AuthContext` memory only; a request interceptor attaches it and a response
interceptor handles `401` by clearing auth and redirecting to `/login?next=`. The shell is an
`AppLayout` (sidebar + topbar + `<Outlet/>`) reached through a `ProtectedRoute`. All visuals
consume Tailwind v4 `@theme` tokens signed off in Task 1.

**Tech Stack:** React 19, TypeScript 5.7, Vite 6, React Router 7, Tailwind v4
(`@tailwindcss/vite`, CSS-first `@theme`), Axios 1.7, **TanStack Query v5 (new — this slice
only)**.

## Global Constraints

- **JWT in memory/context only** — never `localStorage`/`sessionStorage`.
- **TanStack Query is the only new runtime dependency** in M6 (verify v5 supports React 19
  before adding).
- **No `any`.** All HTTP lives in `src/api/`; components never call Axios directly.
- **API base URL only from `VITE_API_BASE_URL`** (fallback `/api` via the Vite dev proxy).
- **Tailwind only** (MUI forbidden). Components consume semantic token classes, not raw hex.
- **No frontend unit tests this slice** — deferred to M6.7. Verify with `tsc --noEmit`,
  `vite build`, and a browser preview check.
- **Admin metrics deferred** — build `RoleRoute` but no admin screen.
- **Do not touch** backend code, database, or API contracts.
- Contract facts: validation `400` → single joined `message` string; not-owner → `404`;
  login → `{accessToken, tokenType, expiresAt}`; `/me` → `{id, email, role}`.

### Task 5: AuthContext (in-memory) + useAuth

**Files:**
- Create: `frontend/src/context/AuthContext.tsx`
- Create: `frontend/src/hooks/useAuth.ts`

**Interfaces:**
- Consumes: `setAuthHandlers` (Task 4); `Role` (Task 3).
- Produces:
  - `interface AuthUser { id: number; email: string; role: Role }`
  - `interface AuthState { token: string | null; user: AuthUser | null; isAuthenticated: boolean; login(token: string, user: AuthUser): void; logout(): void }`
  - `AuthProvider` — holds `token`/`user` in `useState` (memory only), registers
    `getToken`/`onUnauthorized` with the client on mount, exposes state via context.
  - `useAuth(): AuthState` (Task 6, layout, and M6.2 consume this).

- [ ] **Step 1: Define the context + `AuthProvider`** with in-memory state and
  `login`/`logout`. `onUnauthorized` = `logout()` (redirect is handled where routing is
  available — see Task 6 note).
- [ ] **Step 2: Implement `useAuth`** with a guard that throws if used outside the provider.
- [ ] **Step 3: Verify** `npx tsc --noEmit` passes.

> Note: the `401` → `/login?next=` **redirect** is performed by `ProtectedRoute` (Task 6)
> reacting to `isAuthenticated`, plus a one-time redirect on `onUnauthorized`; this keeps
> navigation logic inside the Router tree.

### Task 7: Core UI primitives

**Files:**
- Create under `frontend/src/components/ui/`: `Button.tsx`, `Input.tsx`, `Card.tsx`,
  `Spinner.tsx`, `EmptyState.tsx`, `ErrorState.tsx`, `Alert.tsx`
- (Optional) `frontend/src/components/ui/index.ts` barrel export.

**Interfaces (props, all token-styled, a11y-correct):**
- `Button` — `variant?: "primary" | "secondary" | "ghost" | "danger"`, `isLoading?: boolean`
  (shows `Spinner`, disables), plus native button props. Visible focus ring.
- `Input` — labeled: `label: string`, `error?: string`, native input props; associates
  `<label htmlFor>` + `aria-invalid`/`aria-describedby` when `error` set.
- `Card` — `title?`, `children`; the standard bordered/rounded surface.
- `Spinner` — `size?: "sm" | "md"`; `role="status"` + visually-hidden label.
- `EmptyState` — `title`, `description?`, `action?: ReactNode` (CTA slot).
- `ErrorState` — `message: string`, `onRetry?: () => void`.
- `Alert` — `tone: "error" | "success" | "info"`, `children`; used as the form-level banner;
  `role="alert"` for error tone.

- [ ] **Step 1: Implement each primitive** consuming the approved tokens (Task 1). No page
  logic. Match the retired `LandingPage` idiom (bordered rounded cards) as the visual base.
- [ ] **Step 2: Verify** `npx tsc --noEmit` and `npm run build` pass.
- [ ] **Step 3: Manual check** — render a throwaway gallery route (removed before commit) or
  confirm via the shell page in Task 9.
